API ENDPOINTS
================================================================================

GET /api/audio/[id]
  Purpose: Stream audio file
  Strategy: CDN redirect (307)
  Cache: 1 year, immutable
  Features: Range requests, mobile-optimized

GET /api/audio/metadata/[id]
  Purpose: Fast metadata retrieval
  Cache: 1 hour
  Features: Blob status check, validation

GET /api/audio/list
  Purpose: List all audio files
  Cache: 5 minutes
  Features: Chapter/featured filtering, batch enrichment
  Query Params: ?chapter=X&featured=true&limit=N

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

If endpoints don't work:
1. Check .env.local exists and has correct tokens
2. Verify @vercel/blob is installed
3. Check Vercel dashboard for blob store
4. Review browser console for errors
5. Check Vercel logs for server errors
6. Verify tokens have correct permissions

Common Issues:
- 404 errors: Audio not uploaded to blob yet (expected)
- 500 errors: Check BLOB_READ_WRITE_TOKEN
- CORS errors: Check OPTIONS handler
- Range errors: Verify blob supports ranges (it does)
